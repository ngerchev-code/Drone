# DroneBase: енциклопедия + FPV сглобяване + хангар

```bash
npm start      # http://localhost:8081
npm test
```
Работи и с всеки статичен сървър (`python3 -m http.server`), може да се публикува в GitHub Pages / Netlify.

## Функции
- **Енциклопедия**: 29 модела в 4 категории (граждански, FPV, военни, транспортни), търсене, филтри,
  подреждане по тегло, скорост, обхват, време за полет и товар, детайлен изглед с EASA подсказка.
- **Сравнение**: до 4 дрона един до друг, като най-добрата стойност по всеки параметър е маркирана.
- **FPV сглобяване**: 8 слота за части и готови сглобки. Проверява:
  - перка ↔ рамка, отвори за мотори ↔ рамка, FC/ESC стек ↔ рамка
  - KV ↔ брой клетки, ESC ↔ клетки, ESC ток ↔ мотор
  - видео система ↔ очила, капацитет на батерията за пиков ток
  - оценки: тегло (AUW), тяга/тегло, време за полет (зависване и агресивно), цена, EASA категория
  - линк за споделяне на сглобката
- **Хангар**: моите дронове, полетен дневник (налет, цикли на батериите), документи със срокове
  и предупреждение 30 дни преди изтичане. Пази се в localStorage.

## Структура
```
data/drones.js       база данни с дроновете + EASA подсказки
data/fpv-parts.js    каталог с FPV части + готови сглобки
src/builder.js       логика за съвместимост и оценки (чисти функции, тествани)
public/js/app.js     интерфейс
index.html, serve.js
```

## Добавяне на дрон
Добави обект в `data/drones.js` със същите полета. `npm test` проверява уникалните id и категориите.
Стойностите са ориентировъчни, от публични източници.
