# Drone

Платформа за дронове от всички типове: граждански, FPV, военни (енциклопедично) и транспортни.
Проектът се състои от отделни части, които после ще се обединят в едно приложение.

| Директория | Продукт | Какво прави |
|---|---|---|
| [`encyclopedia/`](encyclopedia/) | **DroneBase** | Енциклопедия на всички дронове, сравнение, FPV сглобяване с проверка за съвместимост, личен хангар (флот, полетен дневник, срокове на документи) |
| [`tracker/`](tracker/) | **DroneRadar** | Жива карта на дроновете чрез Remote ID (ASTM F3411), геозони за България, „мога ли да летя тук“ |
| [`android/`](android/) | **DroneRadar приемник** | Android приложение: засича Remote ID по Bluetooth/WiFi, показва дроновете наоколо, праща към картата |

Уеб проектите работят **само с Node.js ≥ 20, без `npm install`**. APK-то на Android приложението се сглобява автоматично в GitHub Actions (виж [`android/README.md`](android/README.md)).

```bash
# Енциклопедия → http://localhost:8081
cd encyclopedia && npm start

# Тракер с демо дронове над София → http://localhost:8080
cd tracker && npm run demo

# Тестове
(cd encyclopedia && npm test) && (cd tracker && npm test)
```

## Защо това е ниша
- Няма едно място за **всички** дронове. DJI Fly е само за DJI, AirData е само дневник, RotorBuilds е само за FPV.
- **PCPartPicker за FPV** (сглобяване с автоматична проверка на съвместимостта) практически липсва.
- **Remote ID** е задължителен в ЕС и САЩ от 2024 г., но няма потребителски „Flightradar24 за дронове“ с мрежа от приемници.
- България и Балканите почти нямат приложение за геозони и правилата на EASA на български.

## Roadmap
1. ✅ Прототипи (тази версия)
2. ✅ Android приемник за Remote ID ([`android/`](android/)). Следват WiFi NaN и карта в приложението
3. Официални геозони от ГВА/ДП РВД, NOTAM, времето (вятър, Kp индекс)
4. Акаунти и синхронизация на хангара, импорт на DJI/Betaflight/EdgeTX логове
5. Разширяване на базата данни (стотици модели, части с цени от магазини, партньорски линкове)
6. Обединено мобилно приложение (Flutter), стационарни приемници ESP32 (B2B)

> Военната секция е само енциклопедия от открити източници. Без жив тракинг на военни операции.
