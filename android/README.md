# DroneRadar приемник (Android)

Превръща телефона в приемник за **Remote ID**: засича дроновете наоколо по Bluetooth и WiFi,
показва ги на екрана (работи и без интернет) и по избор праща суровите сигнали към
DroneRadar сървъра (`tracker/`), за да се появят на общата жива карта.

## Как да го инсталираш
1. Отвори **Actions** в GitHub → последният успешен **Build** → **Artifacts** → `droneradar-receiver-debug`.
2. Разархивирай и инсталирай `app-debug.apk` на телефона (Android 8.0+; трябва да разрешиш „инсталиране от неизвестни източници“).

Или локално с Android Studio / Android SDK: `cd android && ./gradlew :app:assembleDebug`.

## Как да го изпробваш без дрон
1. На компютъра: `cd tracker && npm start`.
2. В приложението: включи **Демо режим** и **Изпращай към сървъра**. За адрес въведи
   `http://<IP на компютъра>:8080` (телефон в същата WiFi мрежа) или `http://10.0.2.2:8080` (емулатор).
3. **Започни сканиране**. Четири демо дрона кръжат около теб и се появяват и в приложението,
   и на картата на http://localhost:8080.

С истински дрон изключи демо режима. Remote ID излъчват DJI Mini 4 Pro, Air 3, Mavic 3 и всички
дронове с C-клас в ЕС, както и външните модули (Dronetag, Aerobits).

## Какво засича

| Транспорт | Статус | Бележка |
|---|---|---|
| Bluetooth 4 Legacy | ✅ | Всички телефони |
| Bluetooth 5 Long Range (Coded PHY) | ✅ | Ако чипът го поддържа (показва се в статуса) |
| WiFi Beacon | ✅ | Android 11+. Android позволява сканиране само 4 пъти на 2 минути, затова е на всеки 30 s |
| WiFi NaN | ⏳ | Следваща версия |

## Структура
```
core/   чиста Kotlin библиотека, без Android: декодер ASTM F3411, парсери за BLE/WiFi,
        локален tracker, batcher за сървъра, енкодер + демо флот. 17 unit теста:
          ./gradlew -p core test      (не изисква Android SDK)
app/    Android приложение (Jetpack Compose):
          ScannerService   foreground service: BLE + WiFi сканиране, локация, изпращане
          ReceiverState    общо състояние (StateFlow) между service и екрана
          MainActivity     статус, настройки, списък с дронове наоколо
```

Kotlin декодерът е проверен **байт по байт** срещу JS енкодера на сървъра (общ тестов вектор),
а реална партида от Kotlin batcher-а е изпратена до Node сървъра и приета (end-to-end).

## Поверителност
- `receiverId` е случаен UUID и не е свързан с потребителя.
- Позицията на телефона се праща **огрубена до ~100 m** и само ако е включено изпращането.
- Позицията на пилота се показва в приложението, както я излъчва дронът. Публичната карта на сървъра я огрубява до ~1 km.

## Известни ограничения на прототипа
- `usesCleartextTraffic=true` позволява http към локален сървър. В продукция трябва само https.
- Release версията е подписана с debug ключ.
- Няма карта в самото приложение (следва MapLibre) и няма история на засичанията.
